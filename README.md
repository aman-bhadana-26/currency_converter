# Currency Converter

A simple and elegant currency converter web application that provides real-time exchange rates for 160+ currencies.

## Features

- Real-time currency conversion
- Support for 160+ world currencies
- Dynamic flag display for selected currencies
- Clean and modern user interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- ExchangeRate-API for live exchange rates
- FlagsAPI for country flags

## How to Use

1. Enter the amount you want to convert
2. Select the currency you're converting from
3. Select the currency you're converting to
4. Click "Get Exchange Rate" to see the conversion

## Getting Started / Local Setup

To run this project locally, you don't need any special server. You can follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aman-bhadana-26/currency_converter.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd currency_converter
   ```
3. **Open the application:**
   - Double-click `index.html` to open it directly in any modern web browser.
   - Alternatively, use an editor extension like Live Server in VS Code to run it.

## Live Demo

Simply open `index.html` in your browser to start using the converter.

## API

This project uses [ExchangeRate-API](https://api.exchangerate-api.com/) for fetching real-time exchange rates.
